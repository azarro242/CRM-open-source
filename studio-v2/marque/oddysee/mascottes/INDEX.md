# Mascottes Oddysee — index

Illustrations fournies par le client le 2026-10-24 pour **toutes les vidéos de l'agence
Oddysee**, envoyées par lots de cinq (d'autres lots suivront).

Style : vraie **tête en photo noir et blanc**, grande, posée sur un **corps en bâton violet**
(≈ `#5A14D2`, cohérent avec le violet de marque `#632BC5`). Même principe que la mascotte
de la référence REF-02, aux couleurs d'Oddysee.

Fichiers : WebP 1024 × 1536, **fond transparent** (vérifié sur le lot 1).
Nommage : `NN-personnage-emotion.webp`, NN = ordre de réception.

## Règles d'utilisation

- **Une émotion par phrase** : la mascotte change d'expression quand le propos change, au mot
  près (comme REF-02). On remplace l'image par un « pop » opaque (échelle), jamais un fondu.
- **Même personnage dans une séquence** ; deux personnages = dialogue ou avant / après
  (ex. 16 femme inquiète → 13 femme grand sourire).
- **Direction du regard et du geste** : 22 désigne vers la gauche → mascotte à **droite** du
  cadre, élément désigné à **gauche**. 26 marche vers la gauche → entre par la droite.
- Chaque apparition utilise **sa propre copie de fichier** (règle « source d'image distincte »
  de `QUALITE.md`) : dupliquer le fichier sous un autre nom si une émotion revient.
- La tête ne passe **jamais** sous un sous-titre ni sous un texte ; rester dans les zones de
  sécurité 9:16 (rien d'important au-dessus de 170 px ni sous 1640 px).

## Ajouter un nouveau lot

1. Le client envoie cinq images dans un **nouveau message** (ou les dépose sur GitHub dans ce
   dossier).
2. Vérifier la transparence, nommer `NN-personnage-emotion.webp` à la suite, compléter le
   catalogue et le tableau « quel moment ».
3. Ajouter une planche de contrôle `planche-lotXX.png`.
